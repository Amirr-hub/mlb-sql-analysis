# ⚾ MLB SQL Analysis

A SQL data analysis project exploring historical Major League Baseball player data, schools, salaries, and career statistics using PostgreSQL.

## Overview

This project analyzes historical MLB data using SQL to answer business-style questions about:

- Schools producing MLB players
- Club salary trends
- Career longevity
- Player insights
- Historical baseball insights

The objective was to demonstrate advanced SQL skills including:

- Complex JOINs
- CTEs
- Window Functions
- Aggregate Functions
- Subqueries
- CASE Statements

## Business Questions

### School Analysis

- Which schools produced the most MLB players?
- What are the names of the top 3 schools that produced the most players?
- What are the names of the schools with the most decades of player contributions?

### Salary Analysis

- Which teams spend the most?
- Which teams reached $1 billion in cumulative spending first?

### Career Analysis

- Longest careers
- Most games played
- Career batting leaders
